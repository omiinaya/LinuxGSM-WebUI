# Contributing

Thanks for your interest in contributing to LinuxGSM-WebUI!

## Getting Started

```bash
git clone https://github.com/omiinaya/LinuxGSM-WebUI.git
cd LinuxGSM-WebUI
npm install
```

## Development

Start the dev server:

```bash
npm run dev
```

- **Lint:** `npm run lint`
- **Build:** `npm run build`

## Stack

- Next.js 14 (App Router)
- React 18, TypeScript
- Tailwind CSS + shadcn/ui
- Zustand state management

## Commit Messages

```
type: concise subject
```
